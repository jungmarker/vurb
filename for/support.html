Use cases / Customer support

Speech to text for support: clear the queue with your voice

Good support replies are long and specific. Say them instead of typing them, in whichever help desk you use.

Workflows

Examples of what you'd say and what ends up in the text field.

Ticket replies

Talk through the fix, then read it over before sending.

Said

“Thanks for the details. It looks like the export is timing out because the file is over the limit. If you split it by month it should go through”

Typed

Thanks for the details. It looks like the export is timing out because the file is over the limit. If you split it by month, it should go through.

Customer already tried clearing cache and reinstalling. Issue only happens on the Windows app.
