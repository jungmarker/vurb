System requirements

macOSmacOS 13 or later, Apple Silicon or Intel (separate downloads). Apple Silicon recommended for the Best model.
WindowsWindows 10 or 11, x64.
Linuxx64, X11 session. Wayland isn't supported yet.
Disk148 MB to 574 MB for the speech model, depending on which one you choose, plus the app.

First run

  1. Install and open Vurb. If you see a warning about an unidentified developer, see the next section.
  2. Allow the microphone. Your OS will ask the first time you dictate.
  3. On a Mac, allow Accessibility. Vurb needs it to type into other apps: System Settings → Privacy & Security → Accessibility, then turn on Vurb. Without it, text is copied to the clipboard instead of typed.
  4. Let the speech model download. Apple Silicon Macs start with Best (574 MB); other computers start with Balanced (190 MB). You can switch models in settings.
  5. Hold your key and talk. fn on a Mac, Right Control on Windows and Linux.

Unsigned installer warnings

The beta installers aren't code-signed yet, so your OS will warn you the first time. Here's how to open it anyway.

macOS

  1. Open Vurb once. macOS will say it can't verify the developer. Click Done.
  2. Open System Settings → Privacy & Security.
  3. Scroll down to the message about Vurb and click Open Anyway, then confirm.

Windows

  1. Run the installer. If you see “Windows protected your PC”, click More info.
  2. Click Run anyway.

Only do this for files downloaded from vurb.me or our GitHub Releases page.
